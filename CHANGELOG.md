# Changelog

## 0.1.0 - 2026-08-14

Initial open-source release.

- pluggable homr, oemer, and Audiveris adapters
- image and optional PDF input
- MusicXML/MXL normalization
- structural score validation
- multi-page MusicXML merge
- Type-1 MIDI generation
- part/staff track modes
- FastAPI endpoint and CLI
- Docker and GitHub Actions CI
